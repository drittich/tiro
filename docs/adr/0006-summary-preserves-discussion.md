# The Summary preserves exploratory discussion

Tools like Granola tend to compress meetings into decisions and action items, throwing away brainstorming that produced no immediate outcome but still matters. Our Summary puts a **Discussion** section, organized by Discussion thread, right after the TL;DR. Each thread records the ideas raised (including half-formed ones), the alternatives considered, and the ideas set aside with the reasons. The prompt explicitly says never to drop exploratory content for lacking a decision. Summary length scales with the Meeting. The sections are TL;DR → Discussion → Key points → Decisions → Action items → Open questions, plus a suggested title. Notes take priority over the Transcript. The whole Meeting goes to `deepseek/deepseek-v4.1-flash`, the dateless alias, so it follows updates, (about 1M context) in a single call with no map-reduce, and the prompt template can be edited in Settings. A brainstorming-heavy fixture Transcript guards this behaviour in tests.
